臺北市 YouBike 2.0 即時站點 API

關於這個網頁：GitHub Pages 只能放靜態網頁，無法執行 Flask Server， 所以這裡的地圖為展示模式，讀取 repo 內的 Open Data 資料檔（下載當下的快照）。 要看每分鐘更新的即時資料、使用 CRUD 與 Swagger 的「Try it out」，請在本機啟動 Server： 
git clone https://github.com/VincenTddos/youbike-restful-api.git
cd youbike-restful-api
pip install -r requirements.txt
python rest_server.py          # 之後開啟 http://127.0.0.1:5000/docs
python api_client.py demo      # 另開視窗：Python API Client 實測
